# BrightBites Mega

Original GitHub Pages-ready educational platform. Not affiliated with the BBC.

## Features
- 15 subjects, 300 lesson pages, 600 knowledge checks
- Mixed quizzes, flashcards, study planner, favourites, notes, dark mode, progress
- No build step and no dependencies

## Publish
Upload the contents of this folder to a GitHub repository. In Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`.
